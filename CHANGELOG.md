# Changelog

Notable pkx changes are listed by release. Versions before v1.0 may evolve as the CLI matures.

## 0.5.0 — first public release candidate

- Introduced `pkx add`, `pkx remove` / `pkx rm` and `pkx run` for Node and Composer projects, with explicit selection for ambiguous monorepos.
- Added `pkx status`, `pkx plan`, JSON diagnostics, contextual help and short command aliases.
- Added smarter environment diagnostics, workspace-aware installation and `pkx up`.
- Added completion scripts for Bash, Zsh, Fish and PowerShell.
- Added checksum-verified user-install scripts for Windows, macOS and Linux.
- Added contribution guidelines, code of conduct, issue and PR templates, roadmap and documented release process.
- Hardened CI with native npm smoke coverage and reproducible release archives.

See [v0.5.0 release notes](docs/releases/v0.5.0.md) for availability and limitations.
