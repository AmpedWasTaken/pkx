# Community code of conduct

pkx is a public, volunteer-driven developer project. Issues and reviews should help people participate regardless of experience, identity or background.

## Expectations

- Discuss the code, not someone's worth or identity. Offer actionable criticism.
- Be patient with questions and first contributions; link to docs instead of mocking mistakes.
- Respect different skill levels, perspectives and identities. Harassment, discriminatory attacks, threats and doxxing aren't acceptable.
- Stay on topic. No spam, unsolicited marketing or misleading claims of affiliation.
- Don't publish secrets, personal data or private vulnerability details.

## Moderation and reporting

Maintainers may request edits, remove abusive contributions, limit participation, lock discussions or report serious abuse to GitHub. Decisions should be proportionate to observable behavior.

For ordinary technical disagreements, discuss respectfully in the relevant issue or PR. For harassment or privacy concerns, **do not share sensitive details publicly**. Use [GitHub's content reporting tools](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines) or a private method listed on the repository owner's profile if one becomes available. The project doesn't promise a separate off-platform inbox or response time.

These expectations apply in pkx-managed issues, pull requests, reviews and community spaces.
