# Getting support

pkx is a developer preview maintained by volunteers. No paid support or guaranteed response times are offered.

| Need | Start here |
| --- | --- |
| Install/setup or commands | [Getting started](docs/GETTING_STARTED.md) and `pkx help <command>` |
| Missing tool or incompatible version | `pkx doctor` / `pkx doctor --json` |
| Reproducible bug | [Bug report form](https://github.com/AmpedWasTaken/pkx/issues/new/choose) |
| New workflow or ecosystem | [Feature request](https://github.com/AmpedWasTaken/pkx/issues/new/choose) |
| Design direction | [Roadmap](docs/ROADMAP.md) |
| Vulnerability | [Security policy](SECURITY.md) — never post an exploit publicly |

Before reporting a bug, capture `pkx version`, a `pkx plan`, and a small reproduction. Remove secrets, usernames, private paths and tokens from logs.

GitHub Discussions is not currently enabled. Use the **Question / Help** issue form for setup questions. Discussion features can be enabled later if the community grows enough to moderate them.
