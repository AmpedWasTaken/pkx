# Brand and responsible sharing

**Name:** `pkx` (lowercase)  
**Expansion:** Package eXchange  
**Tagline:** One command. Every ecosystem. Your existing package managers.

Short pitch: "pkx is an open-source CLI that detects package managers in mixed-language repositories and runs the native setup steps for you."

## Assets

- [Primary SVG mark](../assets/pkx-mark.svg)
- [1280×640 social graphic](../assets/social-preview.svg)
- Colors: navy `#0B1221`, periwinkle `#879CFF`, mint `#51DECB`
- Use system/monospace fonts; no bundled font files

Keep contrast and legibility intact. Never imply pkx is affiliated with npm, pip, Composer or another ecosystem.

**Maintainer setup:** GitHub social preview requires a separate upload of an exported **PNG** in repository **Settings → General → Social preview**; committing the SVG alone does not change the shared image.

## Honest announcement copy

> pkx (Package eXchange) is an early open-source Go CLI for repositories that use multiple package managers. Use `pkx status` to see what's there, `pkx plan` to preview commands and `pkx up` to install through native tools. Looking for contributor feedback and reproducible cross-platform test cases: https://github.com/AmpedWasTaken/pkx

Do **not** claim a live bundle registry, automatic runtime installation, stable binaries, user counts, endorsements, tracking, or security sandboxing unless those are actually available.

Share a short real workflow, not "replaces all package managers" hype. Link to a specific reproducible issue when recruiting contributors. There are no referral links or tracking pixels in the project assets.
