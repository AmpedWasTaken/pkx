# pkx v0.5.0

First public release of **pkx — Package eXchange**, the local-first CLI for mixed-language repositories.

## Highlights

- **One setup command:** `pkx up` checks the environment and delegates installation to existing package managers.
- **Inspect before installing:** `pkx status`, `pkx scan`, `pkx plan` and `pkx doctor` (with JSON outputs).
- **Daily package operations:** `pkx add`, `pkx remove`/`pkx rm`, and `pkx run` for supported Node/Composer projects.
- **Mixed-language detection:** npm, pnpm, Yarn, Bun, Composer, pip, uv, Poetry, Cargo and Go modules.
- **Local bundles:** a reviewable `pkx.json`; installed only when explicitly requested.
- **Developer experience:** terminal completion for Bash, Zsh, Fish and PowerShell; human-readable diagnostics.

## Install

Download your platform archive and `SHA256SUMS` from the assets below, verify the checksum, then place the `pkx` executable on your PATH. The supported platforms are Linux, macOS and Windows on x64 and ARM64.

Alternatively, from a reviewed clone of this repository, run `sh scripts/install.sh v0.5.0` (macOS/Linux) or `.\scripts\install.ps1 -Version v0.5.0` (PowerShell). These scripts verify the SHA256 of the downloaded archive and install without elevation; they do not modify PATH automatically.

With Go 1.23+: `go install github.com/AmpedWasTaken/pkx/cmd/pkx@v0.5.0`.

## First steps

```sh
pkx status
pkx plan
pkx up
pkx add axios --dry-run
```

## Compatibility and limitations

This is a **0.x release** and CLI options may evolve before v1.0. pkx preserves native lockfiles; it is not a replacement dependency resolver. It does not install missing system runtimes, detect malicious packages, or roll back native tool changes. Native package managers may execute project and dependency lifecycle scripts. `add`, `remove`, and `run` currently target npm/pnpm/Yarn/Bun/Composer, not every ecosystem supported by `up`. Some workspace/version pin configurations remain best-effort.

Report issues with reproducible, sanitized manifests through the GitHub issue forms. See [Getting started](https://github.com/AmpedWasTaken/pkx/blob/main/docs/GETTING_STARTED.md), [Security](https://github.com/AmpedWasTaken/pkx/blob/main/SECURITY.md), and [Contributing](https://github.com/AmpedWasTaken/pkx/blob/main/CONTRIBUTING.md).
