Install pkx once, then use pkx from any terminal. Automatically recognize npm, pnpm, Composer, Python and more while keeping your existing package managers and lockfiles.

Get pkx — choose your terminal

Windows · CMD or PowerShellUser PATH included
powershell -NoProfile -ExecutionPolicy Bypass -Command "& ([scriptblock]::Create((irm 'https://pkx.ampedwastaken.dev/install.ps1'))) -AddToPath"
Installs the latest verified GitHub release under your user profile and adds its folder to your user PATH. No administrator rights. Open a new terminal and run pkx version.
macOS · LinuxShell PATH included
curl -fsSL https://pkx.ampedwastaken.dev/install.sh | sh -s -- --add-to-path
Requires curl, tar and a SHA256 utility. Installs to ~/.local/bin, updates your shell profile once, and asks you to open a new terminal.

Prefer to review the installer first? Read install.ps1 or install.sh. These scripts verify the downloaded release archive against the official GitHub SHA256SUMS; executing any remotely hosted script still requires trusting its source. A manual binary download is also available.
